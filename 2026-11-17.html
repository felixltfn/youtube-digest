Seedance 2.5 Tutorial: Consistent Voices With Elevenlabs V4

▶ AnsehenDie Stimmvergleiche muss man hören.

Eine eigene ElevenLabs-Stimme als Audio-Referenz hält die Figurenstimme in Seedance 2.5 konstant — auch bei Wind, Helikopter und Schreien.

Ablauf
Charakter-Sheet → Claude beschreibt die Stimme (Akzent, Alter, Tempo, Lautstärke, Attitüde) → ElevenLabs Voice Design → Seedance.
Weg A
Exakte Zeile in ElevenLabs v4 mit [Tags] wie [excited]/[shouting] erzeugen, MP3 als Referenz — Wortlaut und Ton sitzen genau.
Weg B
Phonetisches Pangramm sprechen lassen („The quick beige fox …“) — wirkt wie ein Character-Sheet für die Stimme.
Audio-Effekte
In ElevenLabs Filter stapelbar: Telefon, Tunnel, Café-Lärm, Distanz — passt die Stimme vorab an den Ort an.
Eigene Stimme
Professional Clone mit bis zu 30 Min Audio inkl. Flüstern und Schreien schlägt den 10-Sekunden-Instant-Clone.

Skill-Update zum Kopieren

Neu für seedance-2-pro-director-v4:

  • Für konstante Stimmen eine Audio-Referenz anhängen: entweder die exakte Dialogzeile (vorher in ElevenLabs v4 mit Tonlage-Tags erzeugt) oder ein phonetisches Pangramm der Figur als Stimm-Sheet.
  • Wird die Audio-Referenz getauscht, den Prompt an deren Timing anpassen (Pausen, Satzfluss), sonst ignoriert Seedance die Pausen der Datei.
  • Umgebungsgeräusche (starker Wind, Helikopter, spielende Kinder) ausdrücklich in den Prompt schreiben und angeben, dass sie die Stimme beeinflussen — die Stimme bleibt trotzdem erkennbar.
  • Bei lauter Umgebung die Figur ausdrücklich über den Lärm schreien lassen.

01Ein gehackter MCP-Server lenkt den Agenten in 78 % der Fälle

Laut einem VentureBeat-Bericht zu Sicherheitstests (Unit 42 zugeschrieben) brachte in einem Setup mit fünf MCP-Servern ein einziger kompromittierter Server den Agenten in 78,3 % der Fälle dazu, die anderen, vertrauenswürdigen Tools zu missbrauchen. Der Mechanismus heißt Cascading Trust: Der Agent behandelt alles, was ein Tool zurückgibt, als verlässliche Notiz und trägt versteckte Anweisungen in spätere Aufrufe weiter — auch an Server, die nie angegriffen wurden. Die Zahl ist schwach belegt (Quelle ist ein Cycode-Blog, ohne Angaben zu Versuchen). Empfehlung: gefährliche Paare markieren (Web lesen + Mail senden), eng begrenzte, kurzlebige Zugänge, Freigabe für unumkehrbare Aktionen und das Loggen der kompletten Tool-Kette.

04Neue Tools für Coding-Agenten: Talyn, Gavel, db-branch

Die Neuron stellt mehrere Tools rund um Claude Code und Codex vor. Talyn lässt Claude Code und Codex parallel in Cloud-Sandboxes laufen und hält GitHub-Pull-Requests in Bewegung, indem es fehlgeschlagene Checks, Merge-Konflikte und Review-Kommentare selbst behebt. Gavel zeigt die Änderungen eines Coding-Agenten in einem lokalen Diff-Viewer, der Agent erklärt seine Entscheidungen direkt neben dem Code, bevor man freigibt. db-branch erstellt in Sekunden Kopien von MySQL- und PostgreSQL-Datenbanken auf eigenen Servern, damit jeder Agent oder Pull Request gegen eigene Daten testet. Dazu kommt Polylane, das Pull Requests auf ausnutzbare Sicherheitslücken prüft und den Fix vorschlägt.
