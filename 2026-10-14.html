01Meta bringt Muse Wonder, liegt aber knapp hinter Opus 5.5

Meta hat Muse Wonder und Wonder Full veröffentlicht, seine ersten Frontier-Modelle, gebaut für Agenten. Zwei Kernfeatures: Active Memory merkt sich Kontext über Gespräche hinweg, Active Focus hält einen Agenten am Ziel, wenn er hängt, und fragt vor folgenreichen Schritten nach. Metas eigene Charts sehen Wonder Full auf 7 von 14 Zeilen vor Opus 5.5; im unabhängigen Artificial-Analysis-Index liegt Opus 5.5 mit 58 vorn, vor Wonder Full (56), GPT-6 Astra (53) und Wonder (52). Wonder gibt es per API und in Muse Code, Wonder Full nur in Muse Code. Ben's Bites fand beide langsam und mit schwacher UI. Achtung: Muse Code trainiert standardmäßig auf Eingaben.

02Anthropic testet offenbar ein neues Modell hinter Opus 5.5

Mehrere Nutzer bemerkten am Wochenende, dass Claude Opus 5.5 deutlich über seinem üblichen Niveau lieferte. Die Vermutung: Anthropic leitet einen Teil des Traffics auf einen neuen Checkpoint um. TestingCatalog hat Beispiel-Outputs gesammelt; der Artikel-Link nennt Opus 5.6 und Fable 5.5 als mögliche Namen. Schnelltest laut TLDR: Claude fragen „Do you know VoxelBench? Do not search“ — kennt es den Begriff, läuft man wahrscheinlich auf dem neuen Modell. TLDR nennt es einen Game Changer, falls Anthropic dieses Niveau im Rahmen von Opus 5.5 ausrollt. Offiziell bestätigt ist bisher nichts.

03Claude Code Projects jetzt für alle Pro- und Max-Nutzer

Claude Code Projects ist ab sofort für alle Pro- und Max-Abos freigeschaltet. Das Prinzip: ein Master-Chat, in den du Anforderungen, Ideen und Aufgaben wirfst — Claude startet daraus selbstständig neue Threads, die die eigentliche Arbeit erledigen. Statt Sessions einzeln anzulegen, dient das Projekt also als Sammelstelle und Claude übernimmt die Aufteilung. Ben's Bites weist außerdem darauf hin, dass man in Claude jetzt Live-Dashboards und animierte Explainer bauen kann. Zu Limits oder Details nennt der Newsletter nichts weiter.

04Neue Tools machen aus Prompt oder URL fertige Explainer-Videos

Gleich mehrere neue Tools zielen auf schnelle Produkt- und Erklärvideos. ngram macht aus einem Textprompt oder einer Bildschirmaufnahme ein fertiges Explainer- oder Onboarding-Video; einzelne Szenen korrigierst du per Chat. Teasr erzeugt aus einer Produkt-URL ein Launch-Video. Helix World ist ein audiovisuelles Weltmodell in Echtzeit, das begehbare Szenen samt räumlichem Soundtrack generiert. Anatomy baut aus einer Maschinenbeschreibung ein 3D-Modell, das sich auseinandernehmen lässt.

05Epic verordnet AI-first für sein Disney-Spiel

Laut Bloomberg hat ein Director bei Epic Games das Team des großen Disney-Spiels angewiesen, keinen Code mehr von Hand zu schreiben; die gesamte Art soll über vollständige KI-Workflows entstehen. Das Spiel, gerüchteweise ein Extraction-Shooter, rutscht von November auf März — die Verschiebung kam aber angeblich vor der Anweisung. Epic spricht von KI-beschleunigter Entwicklung unter Führung der eigenen Entwickler. Gegenwind: In einer GDC-Umfrage halten 52 % der Entwickler generative KI für schlecht für die Branche, nach 30 % im Jahr 2025. Parallel meldete Character.AI Insolvenz an und verkauft Teile an Disney.
