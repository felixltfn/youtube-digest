How to Turn One Video into Multiple Camera Angles with AI

▶ AnsehenOb die KI-Winkel echt wirken, muss man sehen.

Aus einem einzigen Stativ-Take erzeugt Seedance 2.5 Edit neue Kamerawinkel — gut zum Kaschieren von Schnitten, ersetzt aber keinen echten Multicam-Dreh.

Clips kürzen
Footage vorher in 4–8-s-Stücke schneiden, nur die Stellen, die einen neuen Winkel brauchen.
Bewegung statt Zoom
Nicht „zoom out“ schreiben, sondern die Kamera physisch zurückfahren lassen — kein digitaler Punch-in.
Settings
16:9, Dauer +1 s Puffer (8 s → 9 s), 720p mit hoher Bitrate, danach separat hochskalieren.
Alles sperren
Im Prompt alles festschreiben, was sich NICHT ändern darf — nur die Kamera bewegt sich.
Grenzen
Je extremer der Winkel, desto mehr erfindet das Modell; für wichtige Drehs echte Kameras.

Skill-Update zum Kopieren

Neu für seedance-footage-vfx:

  • Neue Kamerawinkel aus Locked-off-Footage: Referenzvideo als @video taggen, Komposition des Originals explizit beibehalten und nur die Kamerabewegung beschreiben.
  • Kamerabewegung physisch formulieren (Dolly zurück, Kran hoch) statt „zoom in/out“, sonst entsteht ein digitaler Crop-Look.
  • Lock-Liste: im Prompt alles aufzählen, was unverändert bleiben muss (Person, Set, Licht, Mimik), und nur das eine zu ändernde Element freigeben.
  • Input-Clips auf 4–8 s schneiden; Generierungsdauer 1 s länger als der Clip als Puffer.
  • Multi-Angle in einem 15-s-Clip per Timecode-Blöcken: 0–4 s Original-Wide, 4–8 s Reverse-OTS, 8–12 s Extreme Close-up mit Whip-Pan ins Profil, 12–15 s Wurmperspektive mit Kranfahrt nach oben.
  • 720p mit hoher Bitrate generieren und erst danach hochskalieren — liefert bessere Ergebnisse als direkt höhere Auflösung.

„Kopieren“ holt den fertigen Prompt für claude.ai, der den skill-updater startet.

Nutze den Skill „skill-updater“, um meinen Skill „seedance-footage-vfx“ zu aktualisieren.

01Tavus Griffin: 48 % halten den KI-Videoavatar für einen echten Menschen

Tavus hat Griffin vorgestellt, ein KI-Videomodell für Echtzeit-Gespräche. Statt der üblichen Kette aus Spracherkennung, LLM, Stimme und Avatar-Animation, die nacheinander arbeiten, sieht und hört Griffin zu, während es selbst spricht. Es kann unterbrechen und unterbrochen werden, auf Gesehenes reagieren und Gesicht, Stimme, Blick und Gesten mitten im Gespräch anpassen. In einer firmeneigenen Studie hielten 26 von 54 Personen (48 %) ihr Gegenüber nach einem einminütigen Call für echt — das Vorgängersystem Phoenix-4.5 kam auf 2,4 %. Einschränkung: kleine Stichprobe, Studie von Tavus selbst, Griffin-Lite nur für ausgewählte Tester, während Offenlegungs- und Safety-Funktionen entstehen.

02Claude Code bekommt Mods: eigene UI-Elemente und Event-Hooks per TypeScript

Anthropic hat Mods für Claude Code veröffentlicht. Das sind kleine TypeScript-Funktionen, die in Plugins ausgeliefert werden. Sie können Prompts umschreiben, Tool-Aufrufe blockieren oder wiederholen, Berechtigungen ändern, Ausgaben schwärzen und eigene UI-Elemente direkt in Claude Code zeichnen. Damit lassen sich Funktionen ergänzen oder eingebaute Features ersetzen, ohne Claude Code selbst zu ändern. Für eigene Workflows heißt das: Kontext-Anzeigen, Freigabe-Dialoge oder Automationen direkt im Interface statt über Umwege. Gleichzeitig laufen Mods nicht in einer Sandbox, deshalb nur geprüfte oder selbst gebaute einsetzen. Ebenfalls neu: GitHub Copilot Computer Use: Copilot kann jetzt den Bildschirm lesen und Desktop-Apps ohne API bedienen.

04Runway zeigt mit Project Continuum Echtzeit-Video als Interface

Runway hat Project Continuum vorgestellt, eine Vorschau auf vier Interface-Ideen auf Basis von Echtzeit-Video. Die Spannweite reicht von generierten „Portals“ bis zu interaktiven Welten, die live erzeugt werden. Runway beschreibt das Projekt als frühes Forschungsprojekt in Richtung eines Betriebssystems, das auf generiertem Video statt auf klassischen Fenstern aufbaut. Für KI-Videoproduktion deutet das auf Werkzeuge hin, in denen man Szenen in Echtzeit steuert und erkundet, statt Prompt für Prompt einzeln zu generieren.
