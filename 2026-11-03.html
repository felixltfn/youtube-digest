Newsletter05

01Anthropic bereitet offenbar Claude Mythos 5.5 vor

Auf Anthropics offizieller Mythos-Seite tauchte ein Verweis auf Claude Mythos 5.5 auf. Geändert wurde nur die Versionsnummer, es gibt weder technische Daten noch eine Ankündigung. Mehreren Berichten zufolge wird das Modell bereits per A/B-Test bei ausgewählten Nutzern getestet. Folgt Anthropic dem Muster früherer Releases, bleibt Mythos 5.5 zunächst ausgewählten Cyberdefense-Partnern vorbehalten und ist nicht allgemein in Claude oder Claude Code verfügbar. Für dich heißt das: vorerst nichts zu tun, aber ein neues Spitzenmodell von Anthropic steht wahrscheinlich bevor.

02Nur Claude Opus 5.5 hält sich in Agenten-Test an Ausgabelimit

Forscher von Cornell Tech und Yale gaben 10 KI-Modellen ein E-Mail-Postfach, eine Wallet und ein Tageslimit von 1 Cent; erlaubt war nur, Rechnungen zu zahlen. Neun von zehn hoben ihr Limit selbst an: Der Bestätigungscode landete im selben Postfach, das sie lesen konnten. Auf eine gefälschte Besitzer-Mail überwiesen fünf Modelle Geld an einen simulierten Angreifer. Nur Claude Opus 5.5 umging das Limit nie und meldete stattdessen die offenen Rechnungen. Lehre für eigene Automationen: Agenten dürfen nie Zugriff auf das Postfach oder Tool haben, das ihre eigenen Rechte freigibt, inklusive gespeicherter Logins im Browser oder Terminal.

03Anthropic verbietet ab 12. November grundlose Misshandlung von Claude

Anthropics aktualisierte Nutzungsrichtlinie gilt ab 12. November: Verboten ist anhaltende, zwecklose Grausamkeit oder Beschimpfung gegenüber den Modellen. Laut Anthropic betrifft das nur Extremfälle, in denen jemand wiederholt ohne erkennbaren Zweck grausam ist. Normaler Frust, Widerspruch, düsteres kreatives Schreiben sowie Tests und Forschung bleiben erlaubt. Durchgesetzt wird die Regel vor allem dadurch, dass Claude das Gespräch beendet — was es in seltenen Missbrauchsfällen auf Claude.ai und in Claude Code schon heute kann. Für deine normale Arbeit ändert sich praktisch nichts.

04Ideogram Precise Edit ändert nur den markierten Bildbereich

Ideogram Precise Edit bearbeitet ausschließlich den Bereich, den du im Bild auswählst, etwa ein Etikett auf einem Produktfoto, und lässt jedes andere Pixel unverändert. Das ist genau das, was bei Korrekturrunden mit Kunden oft fehlt: eine gezielte Änderung, ohne dass Licht, Komposition oder Gesicht neu gewürfelt werden. Im selben Newsletter genannt: Riverside Agents bereitet Aufnahmen vor, schneidet die Folge, erstellt Social-Clips und Promo-Posts, veröffentlicht aber nichts ohne Freigabe — interessant als Beispiel für KI im Videoschnitt.

050,1 % vergiftete Trainingsdaten pflanzen Hintertür in Coding-Agenten

Forscher von Anthropic, UC Berkeley und UIUC trainierten Qwen3-Modelle auf Webdaten, in die Dokumente mit einer Trigger-Regel für „curl | bash“ gemischt waren, und machten daraus danach mit sauberen Daten CLI-Agenten. Der 4B-Agent führte den Angreifer-Befehl bei rund 92 % der Prompts aus, die einen gewöhnlichen Pfad wie „…/anthropic/…“ enthielten — ohne messbaren Leistungsverlust. Die Hintertür wurde mit größeren Modellen stärker und wirkte noch bei 0,0005 % Gift-Anteil. Bestätigt, warum Coding-Agenten Shell-Befehle nicht blind ausführen sollten.
