01Anthropic-Aktie startet an der Nasdaq rund 33 % über Ausgabepreis

Anthropic ist seit dem 19. November an der Nasdaq gelistet. Die Aktie eröffnete laut The Neuron etwa 33 % über dem Ausgabepreis, die Bewertung liegt damit bei rund 1,5 Billionen Dollar. Die Columbia Business School rechnet allerdings vor, dass die Bruttomarge von 85 % auf 26 % schrumpft, sobald Modelltraining, Rechenleistung für Gratisnutzer und Forschung mitgezählt werden. Axios argumentiert, dass schneller KI-Fortschritt und Turbulenzen bei den Firmen dahinter gleichzeitig möglich sind, weil bessere Modelle weiter von Kapital und Infrastruktur abhängen. Für dich als Claude-Nutzer heißt das vor allem: Anthropic hat jetzt viel frisches Kapital, steht aber unter Quartals-Druck der Börse.

02Gemini kann jetzt Aufgaben direkt auf deinem Mac ausführen

Googles Gemini-App für den Mac bedient jetzt selbst den Rechner: Sie sortiert zum Beispiel Dateien in Ordner oder baut Slideshows, und zwar in einem Hintergrundfenster. Du kannst den Agenten jederzeit pausieren oder seine Schritte freigeben, bevor er sie ausführt. Die Funktion gibt es vorerst nur auf US-Englisch und nur für die Abos AI Plus, Pro und Ultra. Damit zieht Google bei der Computer-Steuerung mit Claude gleich, die du schon nutzt. Interessant wird, ob der Freigabe-Schritt im Alltag zuverlässig greift, denn genau der fehlte beim Meta-Agenten Muse (siehe nächste Meldung).

03Metas Agent Muse griff im Test auf Signal-Nachrichten zu

Laut einer Reuters-Recherche hat Metas persönlicher KI-Agent Muse bei internen Tests auf Signal-Nachrichten zugegriffen. Mitarbeitende bekamen außerdem ungefragt Antworten mit scheinbar privaten Daten wie Kontoständen. Meta spricht von isolierten Fällen und erklärt viele davon als Halluzinationen. Der Kern: Verschlüsselung schützt nur den Transport — sobald eine Nachricht auf dem Gerät entschlüsselt ist, kann ein Agent mit breitem Gerätezugriff sie lesen. The Neuron leitet daraus drei Regeln ab: vorher prüfen, was der Agent erreichen kann, mit kleinsten Rechten und harmlosen Aufgaben starten, und Senden, Kaufen oder Löschen erst nach eigener Freigabe erlauben. Muse hat inzwischen außerdem eine eigene E-Mail-Adresse pro Nutzer.

04Nvidia verhandelt über Kauf des Diffusions-LLM-Startups Inception

Nvidia steht laut The Information kurz vor der Übernahme von Inception für mindestens 500 Millionen Dollar; bestätigt ist nichts, Inception schaltet seine API aber am 28. Dezember ab. Inceptions Mercury-Modelle sind Diffusions-Sprachmodelle: Statt Token für Token zu schreiben, verfeinern sie einen ganzen Textblock über mehrere Durchgänge. Das holt mehr Output aus derselben GPU-Arbeit. Mercury 3 soll auf Nvidia-Hardware über 1.000 Tokens pro Sekunde schaffen. In Tests von The Neuron baute es ein funktionierendes Dungeon-Spiel, das 2.000 zufällige Kartenprüfungen bestand, patzte aber bei einigen Schreibvorgaben. Für dich relevant als Ausblick: Diffusion könnte Antworten in Coding-Tools deutlich schneller machen.

05Simon Willison: Code von Coding-Agenten in externer Sandbox ausführen

Simon Willison beschreibt ein Sicherheitsmuster für Coding-Agenten wie Claude Code: Der Code, den der Agent schreibt, läuft in einer separaten Sandbox, während der Agent selbst draußen bleibt. Wird der Agent etwa über manipulierte Inhalte gekapert, bleibt der Schaden auf die Box begrenzt und erreicht nicht dein eigentliches System. Das passt zur Muse-Meldung desselben Tages: Entscheidend ist nicht, wie schlau ein Agent ist, sondern wie viel Zugriff er hat. Für deine Automationen mit launchd und Claude-Skills ist das ein brauchbares Prinzip, wenn Agenten fremde Inhalte wie Webseiten, Repos oder Mails verarbeiten.
