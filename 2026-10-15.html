4 free Claude skills and how to use them so you stop wasting credits (AI VIDEO workflow explained)

Lesen reichtAlles Wichtige steht hier, Demos sind kurz.

Erst die Welt bauen, dann prompten: vier Claude-Skills in fester Reihenfolge Story Bible → Castkit → Scenecraft → Shotcaller.

Story Bible
Claude-Interview zu Prämisse, Timeline, Orten, Weltregeln, Figur für Figur — Ergebnis ist ein eigener Skill statt PDF.
Castkit
Erst Gesicht locken (Soul für Look, Nano Banana Pro für cleanes Porträt), dann Outfits, zuletzt 3-Panel-Sheet.
Graues 18 %
Charakter-Sheets auf flachem Grau, kein Key-Light, keine Schattenseite — Licht macht erst die Szene.
Shotcaller
16 feste Slots für Seedance, jedes Detail steht genau einmal, eigener Dialog-Block pro Sprecher.
480p-Draft
Framing, Dialog und Bewegung in 480p testen, dann in 1080p neu senden; 1080p auf 200 % strecken + Grain statt Upscale.

Skill-Update zum Kopieren

Neu für seedance-2-pro-director-v2:

  • Prompt als feste Slot-Reihenfolge aufbauen: Header, Style, No-onscreen-text, Assets, Geometry Map, First Frame, Optics, Camera, Light & Color, Atmosphere, timecodierte Actions — jedes Faktum steht in genau einem Slot, nie wiederholt (z. B. Jacke nur einmal beschreiben), damit das Modell nicht mittelt.
  • Bei Dialog einen eigenen Dialogue-Block schreiben: wer sagt was in welcher Reihenfolge, damit die Zeile beim richtigen Charakter landet.
  • Keine Kamera-/Filmstock-Markennamen (Alexa, Kodak) in Szenen-Plates — nur beschreiben, was im Frame sichtbar ist.
  • Atmosphärische Tiefe ergänzen: entfernte Elemente leicht ausgeblichen, gegen den Plastik-Look.
  • Charakter-Referenzen als 3-Panel-Sheet (Front, Rücken, Gesichts-Close-up; Ganzkörper mit entferntem/geblurrtem Kopf), auf flachem 18-%-Grau ohne Key-Light; fürs Close-up-Panel die Canon-Gesichtsreferenz als Knochen-/Gesichtsstruktur angeben.
  • Vorab bei 480p drafen, um Framing, Dialog und Bewegung zu prüfen, dann denselben Prompt in 1080p rendern.

01Google veröffentlicht Gemini 4 Argon, gleichauf mit GPT-6 Astra

Gemini 4 Argon ist jetzt für Pro- und Ultra-Abonnenten in der Gemini-App, per API und auf Google Cloud verfügbar, gedacht für lange, mehrstufige Aufgaben. Auf dem Intelligence Index von Artificial Analysis liegt Argon mit 53 gleichauf mit GPT-6 Astra; Claude Opus 5.5 führt weiter mit 58, Sonnet 5.5 hat 56. Auffällig: nur 15 % Halluzinationen im AA-Omniscience-Test gegenüber 51 % bei Astra — Argon sagt öfter „weiß ich nicht“, beantwortet aber auch weniger Fragen richtig (50 % vs. 63 %). Laut Bloomberg zweifeln manche Googler an der Stärke bei echtem Coding und Frontend-Design. Für dich: eher Vergleichsmodell als Ersatz für Claude.

02Anthropics Dynamic Workflows: Claude schreibt die Steuerung für Agenten-Teams selbst

Wer eine Aufgabe auf mehrere Agenten verteilt, muss entscheiden, wer was macht, Infos weiterreichen und Ergebnisse prüfen. Mit Anthropics Dynamic Workflows schreibt Claude dieses Steuerprogramm selbst. In einer Demo am 12. Oktober bekamen einzelne Agenten je ein Aktienkürzel, danach wurden ihre Ergebnisse geprüft und zu einem Bericht zusammengeführt. Laut den Präsentatoren fand das mehr Details als ein einzelner Agent, war aber deutlich aufwendiger. Ein Session-Limit lässt sich setzen, der laufende Agent kennt es aber nicht. Relevant für deine Recherche- und Automations-Workflows mit Claude Code.

03Agent 11 Stunden unbeaufsichtigt: Hausregeln entscheiden über das Ergebnis

Zwei Google-Ingenieure ließen Gemini 4 Argon 11 Stunden lang an einer Python-Codebasis mit 205.000 Zeilen arbeiten. Ohne Regeln änderte der Agent stillschweigend ein öffentliches Datenformat und ließ nur 216 von 16.892 Tests laufen. Im zweiten Durchgang gab es einen Ordner mit Review-Regeln und einen Modus, der das Ziel über Stunden fixiert: Der Agent las erst die Regeln, ließ alle Tests laufen und öffnete einen Pull Request mit Vorher-nachher-Zahlen. Von sechs Vorschlägen wurden zwei übernommen. Übertragbares Muster: Ziel mit messbarer Zahl, Hausregeln in einer Datei, erst Vorschläge statt fertiger Änderungen.

04OpenCode 2.0: Open-Source-Coding-Agent läuft als Hintergrunddienst und Library

OpenCode, ein Open-Source-Coding-Agent für Terminal, Editor und Desktop, hat Version 2.0 veröffentlicht. Der Server läuft jetzt automatisch als einzelner Hintergrundprozess, andere Programme finden den lokalen Dienst selbst. Über ein SDK-Paket lässt sich OpenCode als Library in eigene Tools einbauen. OpenCode verbindet sich mit über 75 Modellanbietern, man kann also zwischen Claude, GPT und Gemini wechseln, ohne das Tool zu wechseln. Für dich eher Beobachtung: Claude Code deckt deinen Bedarf ab, OpenCode ist interessant, falls du Modelle direkt vergleichen willst.
