5-Step Workflow: How to Make Viral AI Short Dramas (60M Views)

▶ AnsehenDie Takes vorher/nachher muss man sehen.

Der Vorteil ist Realismus: saubere Charaktersheets, ein 3/4-Set-Bild und ein Szenen-Skript machen Seedance-2.5-Dramen, die nicht nach KI aussehen.

Charaktersheet
Grauer Hintergrund, 3 Ansichten (Front, Rücken, Gesichts-Close-up), Gesicht in der Ganzkörper-Front löschen.
Set in 3/4
Location als 3/4-Ansicht generieren — frontal muss Seedance beim Winkelwechsel den Raum raten.
Dramaturgie
Hook = lautester Moment zuerst, dann Kontext, Eskalation, Cliffhanger; Gefühlsumschwung alle 20–30 s.
Akzent
Klang konkret beschreiben (z. B. uvulares R für Französisch) und Stimmbeschreibung in jede Szene mitgeben.
Referenz-Namen
Jede Referenz fest benennen ("Lucy face", "Lucy outfit") und im ganzen Chat gleich verwenden.

Skill-Update zum Kopieren

Neu für seedance-2-pro-director-v2:

  • Charaktersheet für Seedance: grauer Hintergrund (nicht weiß/schwarz), drei Ansichten (Ganzkörper Front, Ganzkörper Rücken, Gesichts-Close-up), Gesicht in der Ganzkörper-Frontansicht entfernen, damit das Modell nur eine Gesichtsreferenz hat.
  • Für Varianten eines Charakters (z. B. Haare offen, ohne Brille) das bestehende Sheet editieren statt neu generieren; kleine Details wie Schmuck als eigenes Close-up mitgeben.
  • Location-Referenz als 3/4-Ansicht erzeugen, die mehr vom Raum zeigt — frontale Plates zwingen das Modell bei neuen Winkeln zum Raten.
  • Akzente nicht benennen, sondern lautlich beschreiben (z. B. weiches uvulares R) und pro Figur eine Stimmbeschreibung in jede Szene übernehmen, in der sie spricht.
  • Bewegung explizit ausschreiben (steht vom roten Stuhl auf, verlässt den Tisch, geht quer durch den Raum zu ihr) und Dialog schon während der Bewegung beginnen lassen, um lange stumme Gänge zu vermeiden.
  • Für eine einzelne Szene an einem neuen Ort den bestehenden Set-Frame als Stilreferenz nutzen und den neuen Raum im Prompt beschreiben.

01Anthropic startet Claude Duet, einen proaktiven Agenten im Hintergrund

Claude Duet ist eine eigene App, in der Claude als proaktiver Agent arbeitet: morgens ein Briefing, alle paar Stunden ein Check der verbundenen Apps, Nachricht nur, wenn etwas wirklich dich braucht. Basis ist Opus 5.5, Duet läuft auf einer eigenen virtuellen Maschine mit Browser und arbeitet daher auch, wenn Laptop und Handy aus sind. Memory, Skills und Connectoren werden übernommen. Vor Senden, Zahlen, Signieren oder Löschen fragt Duet nach; Trading und Überweisungen sind gesperrt, Passwörter sieht es nie. Research Preview nur für US-Pro/Max per Warteliste; Hintergrundarbeit zählt gegen dein Nutzungslimit.

02Claude Mods: Claude Code per eigenem Code umbauen

Ein Latent-Space-Artikel beschreibt Claude Mods: kleine TypeScript- oder JavaScript-Funktionen, die das Verhalten von Claude Code live verändern. Die Idee dreht den Agent-Harness um — statt nur festzulegen, wie der Agent arbeitet, gestaltest du die Schnittstelle zum Menschen, eine Art eigenes "Attention Interface". Damit lässt sich programmieren, wie und wann Claude dich informiert oder um Entscheidungen bittet, und Claude kann diese Mods auch selbst bauen. Für dich relevant, weil du ohnehin Skills, Hooks und Automationen rund um Claude Code baust: Mods sind die nächste Ebene, um Abläufe wie Digest oder Studio direkt in der Oberfläche zu verankern.

03Claude API bekommt erste neue Version seit 2023

Anthropic hat die Claude-API-Version 2026-10-21 veröffentlicht, die erste offizielle Versionsänderung seit 2023. Künftig sollen Versionen häufiger kommen, damit Entwickler Breaking Changes abfangen können, bevor ein neues Modell sie erzwingt. Die alte Version 2023-06-10 ist nicht abgekündigt und funktioniert weiter. Gleichzeitig sind neue Major-Versionen der Anthropic-SDKs und der CLI erschienen, die standardmäßig die neue API nutzen; ein Migrationsguide liegt bei. Praktisch heißt das: Wer eigene Skripte oder Tools mit dem SDK pflegt, sollte beim nächsten SDK-Update kurz prüfen, ob sich etwas am Verhalten ändert.

04Manipuliertes LiteLLM-Paket stahl zwei Stunden lang Zugangsdaten

Am 21. Oktober war auf PyPI eine manipulierte LiteLLM-Version (v1.107.0) rund zwei Stunden online, bevor sie entfernt wurde. LiteLLM ist ein verbreitetes Python-Tool, um Apps mit verschiedenen KI-Modellen zu verbinden; laut SafeDep enthielt das Paket einen Credential-Stealer mit Backdoor. Parallel wurden kritische, über zehn Jahre alte Lücken im PHP-Kern bekannt, gefunden mit Hilfe von GPT-5.6 Sol und unabhängig von Wiz; OpenAI hat dazu einen PHP-Schwachstellen-Checker veröffentlicht. Für dich: In Python-Projekten mit uv/pip Abhängigkeiten pinnen und prüfen, ob LiteLLM irgendwo in einer Umgebung steckt.

05Mehrere Coding-Agenten parallel mit Git-Worktrees

The Neuron erklärt, wie man mehrere Coding-Agenten gleichzeitig laufen lässt, ohne dass sie sich Dateien überschreiben: Jeder Agent bekommt einen eigenen Git-Worktree, also einen eigenen Ordner mit eigenem Branch aus demselben Repo. In Claude Code geht das direkt mit `claude --worktree <name>` (Repo braucht mindestens einen Commit). Wichtig: Arbeit nach Dateien aufteilen, PRs einzeln mergen und dafür eine frische Session nutzen, die Reihenfolge und Konflikte klärt und nach jedem Merge Tests laufen lässt. Stolperfallen: Jeder Worktree braucht eigene Installs (`npm ci`), Dev-Server auf demselben Port kollidieren, eine geteilte Datenbank ist nicht isoliert.
