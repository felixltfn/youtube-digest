Opus 5.5 + HyperFrames liefert in Claude Code brauchbare Motion Graphics für Shorts, Software-Spots und Erklärvideos — fast nur aus einem Prompt.

Claude baut eine animierte Website, die Bild für Bild als Video gerendert wird — jede Farbe, jedes Timing bleibt editierbarer Code.
Test 1: Short
Rohaufnahme rein → Versprecher raus, Layouts, Untertitel, recherchierte Logos/Screenshots; ~15–20 Min auf High.

Schwachstelle
Selbst erzeugte Musik/SFX klingen künstlich — besser lizenzfreie Tracks (Pixabay) mitgeben.

Neu für prompt-optimizer:

  • Assets mitgeben statt generieren lassen, wo Qualität zählt (Sprecherstimme, Musik, SFX).

Claude Code Can Now Automate Your Videos (Remotion + Opus 5.5)

▶ AnsehenLower Thirds und Charts muss man sehen.

Mit dem Remotion-Plugin in Claude Code entstehen Lower Thirds, animierte Charts, App-Spots und Intros aus einem Prompt — bis zum fertigen MP4.

Setup
Claude Desktop (Code-Tab, lokal) + Node.js, danach Rechner neu starten — sonst schlägt die Remotion-Installation fehl.
Skills
Ein Setup-Prompt installiert Projekt + 12 offizielle Remotion-Skills und startet Remotion Studio als Vorschau.
Prompt-Stil
Wie für einen Cutter schreiben: Zweck, Text auf dem Screen, was Sekunde für Sekunde passiert.
Iteration
'Erst Kopie anlegen, nur die Kopie ändern' — und sagen, was bleiben soll (z. B. Glow auf dem Highlight-Balken).
Export
Ein Prompt rendert alle Versionen als MP4 in einen renders-Ordner.

  • Feedback-Prompts für Iterationen: zuerst eine Kopie anlegen lassen und nur die Kopie ändern, damit das Original erhalten bleibt.
  • In Korrektur-Prompts nicht nur benennen, was stört, sondern auch, was ausdrücklich gleich bleiben soll.

01OpenAI startet „Dots“: proaktive Personal Agents mit eigenem Cloud-Computer

Größter Launch der OpenAI DevDay: Dots sind dauerhaft laufende persönliche Agents auf Basis von GPT-6 Astra. Man kann ihnen schreiben oder sie anrufen, sie benennen und ein Avatar wählen — und sie melden sich auch von selbst. Technisch ist ein Dot ein endloser Master-Chat, der Aufgaben annimmt, dafür neue Chats in Codex bzw. ChatGPT Work startet und den Status zurückmeldet. Er läuft auf einem eigenen Computer, der Desktop muss also nicht an sein. Laut Ben's Bites fehlt eine klare Möglichkeit für eigene Memory-/Persönlichkeits-Dateien wie bei OpenClaw; der Nutzen hängt stark von verbundenen Tools ab (Kalender, Mail, Slack, Notion).

02DevDay-Rest: GPT-6.1 Sol, ChatGPT Space, Plugins und Ultrafast

Neben Dots kamen mehrere Updates: GPT-6.1 Sol gilt als echtes Upgrade, nachdem GPT-6 Sol als Rückschritt empfunden wurde. ChatGPT Space ist ein Notion-artiger Dokument-Workspace in ChatGPT, den man mit Agents und Team teilt. Plugins sind OpenAIs neuer Anlauf für Apps in ChatGPT (z. B. tldraws Multiplayer-Canvas). Mit „Sign in with ChatGPT“ lässt sich die eigene ChatGPT-Nutzung in anderen KI-Apps verwenden. Ultrafast lässt GPT-6 Astra bis zu 8× schneller arbeiten, verbraucht aber laut Ben's Bites rund 6× so viel Usage. Außerdem: Codex Cloud hat jetzt wiederverwendbare Environments.

03Google kündigt Gemini 4 Argon an – laut Benchmarks vor GPT-6 Astra und Opus 5.5

Google hat Gemini 4 Argon vorgestellt, ein Frontier-Modell für lang andauerndes Reasoning in Softwareentwicklung, Enterprise-Wissensarbeit und Cybersecurity. Nutzen kann man es noch nicht: Zugang gibt es zunächst nur für ausgewählte Cyber-Verteidiger, breitere Verfügbarkeit soll nach gestaffelten Sicherheitstests folgen. Die veröffentlichten Benchmarks sehen laut Ben's Bites besser aus als GPT-6 Astra und Opus 5.5. Damit ist Google wieder klar im Rennen um das stärkste Modell — relevant, sobald es tatsächlich verfügbar ist und sich in Praxistests gegen Claude behaupten muss.

04Anthropic: Claude for Government GA, Claude Code baut eigene Evals

Claude for Government ist allgemein verfügbar: FedRAMP-High-autorisierte Coding- und Agent-Funktionen für US-Bundes- und Landesbehörden, mit Governance- und Admin-Kontrollen; Claude Code CLI und Claude für Microsoft 365 gibt es dort im Early Access. Laut Ben's Bites kann Claude Code jetzt Evals bauen und sich daran schrittweise verbessern (Hill Climbing). Außerdem warnte Anthropic, dass das offene Modell GLM-5.3 von Z.ai funktionierende Cyberangriffe bauen kann und einfache Tricks dessen Schutzmechanismen umgingen. Parallel bestätigte die FTC eine Untersuchung zu Verbraucherrisiken bei OpenAI, Anthropic und anderen.

05Ideogram 4.5 editiert präzise, Runway zeigt Robotik-Modell Praxis-1

Ideogram 4.5 ist ein neues Bild-Edit-Modell, das gezielte Änderungen vornimmt und den Rest des Bildes unverändert lässt — relevant für Retusche- und Edit-Workflows neben Nano Banana und GPT Image. Runway stellt mit Praxis-1 ein Open-Weight „World Action Model“ vor, das Runways Video-Pretraining in Steuerung für echte Roboter übersetzt. Es läuft aktuell bei frühen Partnern auf deren eigener Hardware und soll in den kommenden Monaten öffentlich erscheinen. Zeigt, wie Runway seine Videomodelle über Kreativ-Tools hinaus als Weltmodelle positioniert.
